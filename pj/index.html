About Pocket Judge

Pocket Judge helps groups run judged contests from start to finish—submissions, scoring, and results in one place.

Sign-up is invite-only with a valid invitation code. Organizers set schedules and rules; participants submit entries; judges score with a simple, consistent flow.

  • Create public or private contests with clear timelines
  • Submit entries with photos and optional captions
  • Judge with slider scoring and structured results
